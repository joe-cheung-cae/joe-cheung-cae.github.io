# joe-cheung-cae.github.io

Personal site for Joe Cheung — CAE & HPC engineer. Landing, public projects, and a small technical-notes archive.

Live: https://joe-cheung-cae.github.io/

## Stack

Astro, Tailwind, MDX, Preact, MiniSearch.

## Develop

```bash
npm install
npm run dev
```

## Deploy

GitHub Pages serves the `gh-pages` branch (built output).

```bash
npm run deploy:github
```

See [DEPLOYMENT.md](./DEPLOYMENT.md) for environment targets.
